# Ponytail prior-art ladder

## Question

What is ponytail's mechanism for "don't reinvent the wheel, reference
excellent products" — and how should Rope grill absorb it as a research
floor?

## Verified Facts

### ponytail ladder (verbatim structure)

Fact: Before writing code, ponytail stops at the first rung that holds:
1. Does this need to exist at all? (YAGNI)
2. Already in this codebase? → reuse, don't rewrite
3. Stdlib does it? → use it
4. Native platform feature? → `<input type="date">` over a picker lib
5. Already-installed dependency solves it? → never add a new one for what a
   few lines can do
6. Can it be one line? → one line
7. Only then: the minimum code that works

The ladder runs *after* understanding the problem, never instead of it:
"Lazy, not negligent… never lazy about understanding the problem. The
ladder shortens the solution, never the reading." Safety floors (trust
boundaries, data-loss handling, security, accessibility) are never cut.
Source: https://github.com/DietrichGebert/ponytail `skills/ponytail/SKILL.md`
(read from a local clone 2026-09-29; MIT).
Verified by: full SKILL.md read + README benchmark section.
Stability: high (skill text is the product).
Implication: Rope's absorption target is rungs 1–5 as a **grill/shape-time
research discipline** (Rope already enforces minimal diffs at go via brief
budgets); the novel part for Rope is that rung lookup is delegated to
explore leaves with web access, not done from model memory.

### rope-explore research mode already supports the floor

Fact: The installed rope-explore preset carries a research-brief mode —
"read-only by default, research briefs add web + one findings artifact"
written under `.rope/research/**` only.
Source: `~/.pi/agent/agents/rope-explore.md` (generated preset, checked
2026-09-29); preset generation lives in skills/rope-harness-presets.
Verified by: preset file read.
Stability: medium (preset is machine-local, regenerated by
rope-harness-presets).
Implication: no preset change is needed; the grill rule only has to
reference the research mode when fanning out.

## Assumptions

- Rung 6 ("one line") and output-terse rules are out of scope for Rope:
  they govern code-writing style, which Rope addresses via Minimal Leaf
  Brief and review axes, not via grill.
